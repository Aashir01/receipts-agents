Don't trust us. Check it.

Every sandbox job is signed by the machine that ran it, then countersigned into a hash-chained ledger. Paste a receipt ID and this page re-checks every signature and hash itself, in your browser, with WebCrypto. The server only hands over the data.

Public keys

The app's key signs the hash of every ledger entry. Executor keys are created in memory when a runner starts and never leave that machine; a fresh VM's key dies with the VM.

Verify offline

  1. On any receipt in the workspace, choose Download proof bundle.
  2. Unzip it and run pip install cryptography && python verify.py . --site https://agentrush.aashirnoman.dev
  3. Or replay the code yourself in the same pinned sandbox image with bash replay.sh.
