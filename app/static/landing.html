Proof, not promises

Most AI products ask you to trust them. Countersign hands you a receipt you can check without trusting us at all.

  1. SIGNED

    By the machine that ran it

    Each executor creates an Ed25519 key in memory when it starts. It signs exactly what it ran: the script, the inputs, the printed output, every file and the image digest. The key never touches a disk, and a fresh VM's key dies with the VM.

    exec-4f2a… signs job 0bdfae979e97
  2. COUNTERSIGNED

    Into a hash-chained ledger

    The app commits every receipt to an append-only ledger on Vultr Object Storage. Each entry carries the previous entry's hash and the app's signature, so changing any old receipt breaks every link after it.

    #1288 prev 9c41f0… sig app-f256…
  3. VERIFIED

    By you, not by us

    The verifier recomputes every hash and signature in your own browser with WebCrypto. Or download the proof bundle and run a 30-line script offline, then replay the code in the same pinned image.

Sealed by design

BLOCKED

Nothing leaves

The analysis sandbox has no network, and the executor VM holds zero secrets. Exfiltration simply fails.

HELD

You decide the risky parts

Code that reaches for the network or secrets, and any submit, buy or send action, pause for a human.

REFUSED

A browser on a short leash

One allowlist proxy per task. Private and cloud-metadata addresses refused; password and card fields never filled.

TRIPPED

Caught red-handed

Every job is seeded with fake cloud keys, an SSH key and a database URL. Touch one and the run is quarantined, with the exact line of code on the receipt.

MASKED

The model never sees your customers

Emails, phones, card numbers and names become tokens like [EMAIL_3] before any text reaches a model, and turn back into real values only on our server.

ZERO

Blast radius, itemised

Every run ends with what it was granted, what it actually touched, and what it tried and was refused, recorded inside the sandbox.

REPRODUCED

Check it yourself

Replay any receipt in a fresh sandbox and compare the SHA-256 of every output, or verify its signatures offline.

DESTROYED

A fresh server per run

Optionally run on a never-used Vultr VM that is deleted afterwards, confirmed through the Vultr API.

ENFORCED

Your rules, as code

A compliance team writes a short policy once: allowed sites, export limits, which files need a fresh VM. Every run obeys it and cites its hash.

Human approval where it mattersRisky code, unfamiliar websites and anything that submits, buys or sends wait for a person.
